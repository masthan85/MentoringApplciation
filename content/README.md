# Mentor Encyclopedia content

Source documents for retrieval, one Markdown file per source in `sources/`, each starting with a front matter block (slug, title, authority tier, volatility, domain, jurisdiction, licence, reviewer and dates). Load them with `make seed`, or add and review them on the admin page.

Only content we have the right to use belongs here: our own playbooks, open standards and public guidance, and vendor documentation whose terms allow it. No copyrighted books or paid bodies of knowledge.

The 15 starter documents are original drafts written for this project. They are unreviewed, so they are tagged `community`. When an expert has checked one, set `reviewer`, `last_reviewed` and a higher `authority_tier`.
